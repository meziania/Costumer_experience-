01 — L’atelier

Une boîte petite. Des livraisons concrètes.

CX Systems est née à Casablanca : pas d’open-space miroir, pas de pitch deck de 40 slides. Juste un atelier qui écoute le métier, code, déploie, puis reste joignable quand quelque chose casse un vendredi à 18h.

On travaille surtout pour des commerces, distributeurs et équipes internes qui ont besoin d’un système fiable — souvent après avoir souffert d’Excel, de logiciels trop génériques, ou de prototypes abandonnés.

02 — Travaux sélectionnés

Ce qui tourne déjà quelque part.

Une sélection honnête — pas une galerie de maquettes. Chaque ligne correspond à un usage réel, une contrainte métier, une mise en production.

  1. 2025 4 apps live

    FidApp

    Fidélité · commerces marocains

    Le client scanne un QR, cumule des visites, sans installer d’app. Monorepo : PWA client, dashboard commerçant, admin, API — QR anti-fraude à rotation.

    React · Node · PostgreSQL · Prisma · PWA

  2. 2025 Mission

    Entrepôt ERP/CRM — Food Group

    Distribution · Dynamics 365 BC

    77 tables documentées à la main (ventes, stock, CRM, RH, finance), pipelines ETL et dashboards Power BI là où il n’y avait presque rien d’écrit.

    SQL Server · n8n · Power BI · T-SQL

  3. 2025 Prod

    2R Parts

    Pièces auto · desktop

    Caisse, stock, crédit client, fournisseurs, factures PDF — un logiciel Windows fait pour le comptoir, pas pour une démo.

    Python · PyQt5 · SQLite

  4. 2025 Mission

    JobGate — studio vidéo

    Recrutement

    Backend Django : entretiens vidéo WebRTC, auth multi-fournisseurs, candidatures et files Celery/Redis.

    Django · WebRTC · PostgreSQL · Celery

  5. 2025 Livré

    Opti Gest

    Optique · Windows / Mac

    Clients, ordonnances, devis, mutuelles CNOPS/CNSS, rappels WhatsApp — données en local (SQLite), sans dépendance cloud obligatoire.

    Electron · React · Express · Prisma

  6. 2025–26 Mission

    GPSI

    Parc IT · Food Group

    Inventaire équipements, tickets SLA, rôles admin/technicien/utilisateur, copilote IA local (Ollama) avec repli heuristique.

    Laravel · Inertia · React · PostgreSQL

  7. 2026 En cours

    SaaS multi-tenant · commerces

03 — Savoir-faire

Trois façons de travailler avec nous.

Produit & SaaS

Plateformes web multi-utilisateurs, PWA, dashboards — quand le métier a besoin d’un outil partagé, pas d’un site vitrine.

Logiciel de comptoir

Applications desktop Windows (et parfois Mac) : POS, stock, facturation. Pensées pour la vitesse au clavier, hors ligne si besoin.

Data & ERP

Remettre de l’ordre dans les données : ETL, Power BI, Dynamics 365 BC, documentation de schémas que personne n’avait écrite.

On préfère un périmètre clair et un outil en production à un “MVP” qui ne sert personne.
